# KAILASH: DIVINE GUARDIAN

An action-packed 3D third-person action game built with **Godot Engine 4.x**, featuring **Lord Ganesha** defending sacred grounds against rogue robotic legions with radiant divine energy.

---

## 🌟 Game Highlights

- **Playable Character**: Lord Ganesha featuring custom terracotta & gold aesthetics, natural bone-rigged locomotion, and divine animation states.
- **Divine Energy Combat**: Unified Left-Mouse-Button divine attacks unleashing radiant golden energy projectiles with explosive impact.
- **Dynamic Third-Person Experience**: Smooth camera orbit, responsive directional controls (W/A/S/D), crosshair targeting, and fluid jump physics.
- **WebGL / Web-Ready**: Specially tuned and optimized for the Godot Compatibility (OpenGL/WebGL) renderer, optimized particle density, and balanced draw calls for smooth in-browser play.

## 🛠️ Requirements & Setup

### Running from Source
1. Download **[Godot Engine 4.x](https://godotengine.org/download)** (Compatibility or Forward+ renderer supported).
2. Clone this repository:
   ```bash
   git clone https://github.com/Sunny-H-12-NIAT/kailash-divine-guardian.git
   ```
3. Open Godot Engine, click **Import**, select `project.godot` inside the repository, and click **Import & Edit**.
4. Press **F5** to run the project.

### Web Export
The project comes pre-configured with the **Web** export preset in `export_presets.cfg`:
```bash
godot --headless --export-release "Web" path/to/build/index.html
```
